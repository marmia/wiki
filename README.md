# Wiki

オーナー用の HTML 形式 Wiki。分野ごとにディレクトリを分け、分野の担当 BOT が中身を作る。公開先：https://marmia.github.io/wiki/

## 役割

- **担当 BOT：** 自分の分野のディレクトリ `<分野>/` の中身を作る。分野 TOP の目次とそのグループ分け、公開前の確認、コミットと push も、担当 BOT が行う。オーナーが「Wiki にして」と頼んだレポートだけを載せる
- **ナレ：** Wiki の外側を持つ。TOP ページ（`index.html`）、共通の CSS（`assets/`）、雛形（`_templates/`）、この規則、新しい分野を TOP に足すこと

## 構成

```
index.html          全分野の TOP（ナレが管理。分野を足すときだけ担当 BOT がナレに頼む）
assets/wiki.css     共通の CSS
_templates/         雛形（domain-index.html、page.html）
<分野>/index.html   分野 TOP。目次（TOC）から個別ページへ移る。目次はグループごとにまとめる
<分野>/<ページ>.html 個別ページ
```

## 書き方

1. `_templates/` の雛形をコピーして使う。CSS は `../assets/wiki.css` を相対パスで読む（Pages のサブパスで動くように、絶対パスは使わない）
2. 個別ページには、パンくずリスト（Wiki ／ 分野 ／ ページ）を付ける
3. 新しいページを作ったら、同じ分野の `index.html` の目次に1行足す。目次はグループごとに `<h3>` の見出しと、その下の `<ul class="toc">` でまとめる。グループ分けは担当 BOT が決める
4. ページ間のリンクは張らない。1本のレポートが1ページで、それぞれ独立したトピックとして書く。ページへの入り口は分野 TOP の目次だけにする
5. 図や画像は、同じ分野のディレクトリに置く（共通の物は `assets/`）
6. `a4-report` で作ったレポートも、個別ページの1種として置いてよい。その場合は、`a4-report` の `print.css` ではなく `assets/wiki.css` を読ませ、パンくずリストを足す

## 載せてはいけないもの（公開リポジトリのため）

- 個人情報、メールアドレス、トークン・パスワードなどの秘密
- 非公開の仕事や他人の情報
- 迷うものは、載せる前にオーナーに聞く

## 公開の手順

担当 BOT が、`wiki-publish` スキル（`~/.agents/skills/wiki-publish/`）の手順で、公開してよい内容かを確認し、コミットして push する。コミットメッセージは `docs: 日本語の要約`。新しい分野を TOP に足すときだけ、ナレに「分野名と一言の説明」を伝える。
